# Yuyay — Web

Aplicación web de Yuyay en React 19, Vite, TypeScript y Tailwind CSS. Publicada en https://yuyay-frontend.vercel.app.

```bash
npm install
npm run dev      # http://localhost:5173, usa el backend local
npm test         # pruebas
npm run lint
npm run build
```

Para usar otro backend, crea `.env.local` con `VITE_API_URL=<url del backend sin /api/v1>`.

Enlaces públicos, funcionalidades, estructura y despliegue: ver el [README principal](../README.md).
